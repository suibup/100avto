# 100Авто — сайт автосервиса (Уфа)

React + TypeScript + Vite + Tailwind CSS v4.

    npm install
    npm run dev      # разработка
    npm run build    # продакшн-сборка в dist/

Контакты, ссылки и рейтинг — `src/data/company.ts`. Услуги — `src/data/services.ts`. Марки — `src/data/brands.ts`.

Перед публикацией:
- подтвердить график работы у владельца и добавить его в `Contacts.tsx` и в Schema.org (`index.html`);
- после выбора домена сделать `og:image` и `image` в разметке абсолютными ссылками;
- заменить иллюстрации услуг на реальные фотографии сервиса, когда они появятся.
